# 怎么测的

## 一句话

> 我们用同一套任务，装和不装都跑；换顺序、多跑几遍，每次从干净状态开始，再看差别站不站得住。

## 结果只有五种说法

| 页面结论 | 白话解释 |
| --- | --- |
| ✅ 真有用 | 多跑几遍后，结果还是明显更好 |
| ❌ 帮倒忙 | 装了以后，结果明显变差 |
| ➖ 没啥差别 | 测得够多，也测得够稳，没看到值得在意的差别（不是绝对一样） |
| ❓ 还说不准 | 现在的结果不够，不能说有用，也不能说没用 |
| 🚧 没法测 | 装不上、环境不支持，或任务不适合；具体原因写清 |

## 判定算法（固定，不许临场发挥）

设主要指标差值区间为 `[L,U]`，正向门槛 `a`，可接受退化幅度 `b`，半宽 `(U-L)/2`。首域采用 `a=b=5` 分，满分 100，半宽要求 ≤5 分。

1. 数据或算法检查失败 → 运行状态「实验无效/待重跑」，不输出能力五状态。
2. 安装失败 / 任务不适用 / 环境不支持 → 「没法测」并附原因。
3. 算法未校验 / 证据缺失 / 结果无法计算 → 拒绝分析，标「待验证/待修复」。
4. 精度达标且 `L>a` → 真有用。
5. 精度达标且 `U<−b` → 帮倒忙。
6. 精度达标且 `L>−b` 且 `U<a` → 没啥差别。
7. 其余（含区间刚好等于阈值、精度不足）→ 还说不准。

## 三张单分开摆，不给总分

**能力** / **好不好用** / **花费与安全**，各看各的。第三张里钱和安全也分栏，绝不算一个总分。不用星级，不搞全能总榜，不拿星数或热度当能力。

## 钱怎么算

- **每干成一件花多少钱** = 全部花费 ÷ 干成数。
- **多干成一件多花多少钱** = 比不装多花的钱 ÷ 多干成的数。
- 一件没干成、或多干成为零，写「不适用」，仍展示实际花费。测不到的不能填 0。

## 有效期

成绩默认只管 90 天，到期退出推荐和排名，历史结论留着。改个日期不算续期。

## 局限

- 「还说不准」「没法测」照常展示，但不参加数字排名。
- 环境、题目、模型或预算不一样，不直接排在一起比。
- 实验环境和网站服务器分开，不在网站机器上运行不可信插件。
- 分数只能从有效证据重算，报告正文可以人工写，成绩、区间和标签不能手填。
