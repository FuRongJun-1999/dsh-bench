## 登记口径（必读）

- 上表是**本仓当前文件**的哈希。为了让仓库可以公开，本轮对真源做了**措辞替换**：把只在本组织内部有意义的代号改成对外可读的表述（例如把某个内部材料机制名改成「预留未公开材料机制」，把内部数据接入名改成「外部数据接入」）。
  **方案的实质主张、规则、阈值和判定算法一字未改**；改动仅限上述代号词面。
- 因此本表哈希与「设计者手里的原始文件」哈希**不同**。原始哈希另由设计者登记；正式实验须绑定**实际用于执行的那一份**的哈希。
- 替换清单可复核：`git log -p -- docs/spec/` 逐条查看。
- 哈希只能检查内容是否一致，不证明内容真实（手册 §13.5）。
